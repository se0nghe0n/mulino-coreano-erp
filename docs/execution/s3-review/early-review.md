## 예약 정지 범위 추가 검토

실제 GPT-6 Astra low가 `56d6be4`에서 QC 부분을 읽기 전용으로
검토해 P2 한 건을 확인했다. `QualityCommands`가 제한/처분 근거
철회 때 segment의 모든 예약을 정지해 행동·고객·정확한 물량 범위가
영향받지 않은 예약도 멈춘다. SELL `[0,20)` 제한과 `[20,100)` 예약,
INTERNAL_MOVE 제한과 SELL 예약, 중첩된 유효 근거 중 하나의 철회가
반례다. 각 예약의 변경 후 적격량을 재판정하도록 수정하고 실제 DB
회귀를 추가한다. 수정·결합 실행 전이므로 아직 OPEN이다.

범위 계산과 특정 제한 해제에서는 추가 확정 결함을 찾지 못했다.
검토자는 테스트를 실행하지 않았고 전체 S3 review로 표시하지 않는다.
