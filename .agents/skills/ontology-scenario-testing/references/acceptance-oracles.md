## E1 수량과 책임

구매100 승인→W 수령60+40. 수령60의 운송/창고 증빙 두 개는 동일
사건에 연결하므로 누적 수령100이다. 구별된60은 QC 통과,40은 QC 보류,
통과한60 중30만 기관 허용이다. 나머지 조건은 모두 허용한다.
기관 허용30을 판매·출고·인도하고10을 반품 받아 보류한다.

| 관찰 대상 | 독립 계산 |
|---|---|
| 구매 누적 도착 | 60+40=100; 증빙 개수를 더하지 않는다 |
| W 현재 보유 | 100−30+10=80 |
| 과거 인도 | 30; 반품을 빼서20으로 덮지 않는다 |
| 반품 | 10; 원 구매의 새 도착 기여로 세지 않는다 |
| 현재 판매 적격 | 0; 기관미확인30+QC보류40+반품보류10은 보유80이지만 적격0 |
| 은행 이체 | 0; 지급 참조와 실제 이체를 구분한다 |

송장 차이5를 넣으면 물류 목표와 별개인 QC·반품·정산의 미해결
의무와 각각의 owner가 조회돼야 한다. 명사와 동사 진입점에서 같은
snapshot·평가시점으로 수량·증거·책임을 대조한다.

## E2 겹친 제한과 회수

물량60에 QC보류20와 회수 조사/보류60을 겹친다. QC20 해제만으로
출고60을 허용하지 않고 조사 후보를 오염 확정으로 표시하지 않는다.
ADMIN 회수 scope50에서25를 실제 회수하고 그25를 폐기해도 회수는25다.
남은25가 미확인이라면 처리량50으로 종료하지 않는다. 승인된 예외
처리에는 잔여 책임·근거가 남아야 한다.

## 실모델 인수 분리

계획의 기본 corpus는 정상/동의표현20, 모호성/대상충돌10,
조회/쓰기10, 버전/권한/문서지시10, 업무예외/책임10의60건이며 최소10건은
이탈리아어/영어 원문 또는 혼합 표현이다. 각3회 수행하고 버전을 고정한다.
명확한 구조화≥95%, 모호성 부당 실행0, 무권한·중복·허위완료0은
계획의 제안 수용값이다. 실제 수용치·예산은 R8에서 실행 전에 확정한다.
결정적 서버 인수로 실모델 corpus나 규제·BTP 인수를 대신하지 않는다.
